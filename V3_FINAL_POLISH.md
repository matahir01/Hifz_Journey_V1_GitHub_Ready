# Hifz Journey V3 polish candidate

This package keeps the V3 Tarteel on-device recitation coach and adds the agreed product/UI polish:

- Version normalized to 3.0.0+13.
- Home hero redesigned around Arabic greeting and a Hifz Journey identity.
- Settings footer cleaned to product name + version only.
- Preferred reciter selector made responsive.
- Ayah reader redesigned with Surah identity, Arabic-first typography, Bismillah treatment, compact synchronized player, offline/bookmark/test actions, and direct Mushaf access.
- Mushaf text mode redesigned as a page-like reading surface with Surah headers, Bismillah treatment, ornamental ayah numbers, Arabic typography fallbacks, and page navigation.
- Tarteel live recognition keeps the model resident and uses slightly more responsive voice gating; duplicate live partials no longer trigger redundant UI work.
- Existing Al Quran Cloud streaming/offline audio and the fixed wait-for-completion synchronization are preserved.

No Qur'an text was altered by these UI changes.

# Contributing to Hifz Journey

## Development

1. Install the current stable Flutter SDK.
2. Run `flutter pub get`.
3. Run `dart format lib test`.
4. Run `flutter analyze`.
5. Run `flutter test`.

## Qur'an data integrity

Do not edit Qur'an text casually or manually. Changes to canonical Qur'an data must include provenance, validation, and tests before being merged.

## Pull requests

Keep changes focused, explain architectural decisions, and include tests for new domain logic.

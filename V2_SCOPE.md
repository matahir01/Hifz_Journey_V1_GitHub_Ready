# Hifz Journey V2

V2 turns the working offline-first V1 into a guided memorization companion.

## Implemented in this V2 foundation
- First-run Hifz onboarding.
- User-selectable starting Surah.
- Sustainable 2–10 ayah daily target.
- Reminder-time selection during setup.
- Hifz plan begins from the user's chosen starting point.
- Daily engine now returns the full remaining daily target (fixes V1's one-ayah-at-a-time plan bug).
- Revision remains retention-first and due-date driven.
- Home terminology distinguishes a daily target from already-introduced ayahs.
- Existing Qur'an reader, search, bookmarks, Juz/Page navigation, recall test, progress and offline database are preserved.

## V2 next modules (architecture reserved)
1. Downloadable offline reciter packs and repeat controls.
2. Mushaf page layout mode.
3. Rich three-level recall grading and weak-ayah dashboard.
4. Session history/calendar and streak analytics.
5. Local backup/restore.
6. Optional V2.1 recitation coach interface.

The app remains offline-first. No account, Firebase, paid backend, teacher account, or family cloud system is required for V2.
